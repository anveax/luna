LuNA 7 "AZ" System
==================

See `examples` for examples.

Run `make` to build everything. Requires `flex`, `bison`, `c/c++`,
`node.js` and `python`. And `make`.

Run `make test` to perform self-test

Run `make clean` to purge repo.

## For developers

To add or update any components in the startup pipeline
you need to read the [instructions](./launch_pipeline/readme.md).
